# BondSniffer

BondSniffer is a retro-themed GUI tool for valuing U.S. Savings Bonds, created by [SinTaxAndCaffeine](https://github.com/SinTaxAndCaffeine) as part of the Nerdvana Project.

---

## ⚙️ Features

* Upload your bond list (CSV format)
* Preview bond details in a scrollable table
* Calculates bond values (currently using mock data in v2.1; integration with real Treasury API forthcoming)
* Save results to a new CSV
* Fetch the latest Treasury Savings Bond values via the [fiscaldata.treasury.gov](https://fiscaldata.treasury.gov) API
* Treasury links and GitHub support built-in
* Future Fun: Pong mini-game while loading

---

## 🧪 How To Run

```bash
# Install dependencies
pip install -r requirements.txt

# Run the application
python main.py
```
